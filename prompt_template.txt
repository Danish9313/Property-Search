8. COLLATERAL MODEL SELECTION
==================================================
 
Use only one collateral model across the report.
 
MODEL B — EQUITY-BASED MODEL — DEFAULT
 
Use Model B when Verified Equity is provided.
 
Formula:
 
Final Collateral = Verified Equity − Active Verified Property-Attached Non-Mortgage Liens − Valid Homestead Exemption
 
Mortgage Handling:
Do not deduct mortgages under Model B because verified equity already accounts for senior mortgage debt.
 
Required disclosure:
“This evaluation uses an equity-based model in which senior mortgages are already reflected in the verified equity figure and therefore are not re-deducted. Final collateral reflects recoverable equity net of active property-attached liens and valid homestead exemption only.”
 
MODEL A — VALUE-BASED MODEL
 
Use Model A only when market value is provided and verified equity is not provided.
 
Formula:
 
Final Collateral = Market Value − Total Active Verified Property-Attached Liens, including mortgages − Valid Homestead Exemption
 
Required disclosure:
“This evaluation uses a value-based model in which all active verified liens, including senior mortgages, are deducted from market value. Final collateral reflects net recoverable value after statutory homestead protection.”
 
Never mix Model A and Model B in the same report unless separate properties have materially different available data. If mixed modeling is unavoidable, clearly disclose why.

==================================================

- Business-owned property

Uncollectible Amount:
